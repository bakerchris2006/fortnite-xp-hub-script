## What this does

Fortnite XP is a browser-based script utility meant to simplify XP accumulation during Fortnite play sessions. Rather than repeating the same actions by hand, it automates targeted in-game interactions so experience can keep building with less manual input. Because it runs in a web interface, there is no need for complicated setup, extra installs, or system-level changes.

Once launched on supported web platforms, the script can take over repetitive work while you keep the tab open.
